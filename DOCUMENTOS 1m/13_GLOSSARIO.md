# Glossário

| Termo | Definição |
| --- | --- |
| Alocação | Reserva de memória para um processo. |
| Bloco | Área contígua da memória simulada. |
| CPU | Unidade simulada que executa um processo por vez. |
| E/S | Entrada e saída; operação que pode bloquear um processo. |
| First Fit | Estratégia que escolhe o primeiro bloco livre suficiente. |
| Fila de prontos | Estrutura com processos aptos a receber CPU. |
| Fragmentação | Espaços livres separados que podem dificultar uma alocação. |
| PID | Identificador único de um processo. |
| Processo | Programa simulado com estado, tempo e recursos. |
| Quantum | Intervalo lógico de CPU concedido em uma rodada. |
| Round Robin | Algoritmo que alterna processos em uma fila circular. |
| Semáforo | Estrutura de sincronização com operações P e V. |
| Sistema hospedeiro | Computador e sistema operacional reais onde o simulador executa. |
| Simulação | Representação controlada de conceitos, sem controlar hardware real. |
| Estado | Fase do ciclo de vida de um processo. |
