# Requisitos Não Funcionais 

RNF00 - O sistema será desenvolvido na linguagem C.

RNF01 — Execução em terminal

O sistema deverá funcionar por meio de uma interface de linha de comando/terminal.

RNF02 — Validação de entradas

O sistema deverá realizar tratamento e validação das entradas fornecidas pelo usuário.

RNF03 — Organização do código

O código deverá apresentar organização e legibilidade adequadas.

RNF04 — Modularização

O sistema deverá ser desenvolvido de forma modular, permitindo organizar as diferentes funcionalidades do simulador.

RNF05 — Documentação do código

O código deverá possuir documentação e comentários que auxiliem na compreensão de sua implementação.

RNF06 — Funcionamento correto

As funcionalidades implementadas deverão funcionar corretamente e de maneira integrada.

RNF07 — Finalidade educacional

O sistema deverá funcionar como uma simulação educacional, não como um sistema operacional real.
